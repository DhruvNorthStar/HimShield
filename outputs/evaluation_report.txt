VERDICT
Random Forest is the better model on this data.

On AUC, the metric that does not depend on a threshold, Random Forest scores 0.9604 against 0.9404, a gap of 0.0200.
Resampling the test set 1,000 times puts that gap between +0.0157 and +0.0242, which excludes zero. The difference is larger than the noise in a test set this size.

SVM (RBF): at the usual 0.5 cut-off it catches 90% of real landslides (1355 of 1513), and 76% of the places it flags are real. It misses 158 landslides and raises 430 false alarms.
Random Forest: at the usual 0.5 cut-off it catches 89% of real landslides (1341 of 1513), and 83% of the places it flags are real. It misses 172 landslides and raises 272 false alarms.

Note the split decision: Random Forest ranks better overall, but SVM (RBF) catches more landslides at the default threshold. For a hazard map, missing a real landslide is worse than sending someone to check a safe slope, so that matters.

Why the ranking comes out this way:
- Random Forest splits on thresholds, which is the shape terrain failure actually takes: risk changes sharply around a slope angle rather than sliding smoothly.
- It also handles the one-hot rock and land-cover columns without needing them to be comparable in scale, and it models interactions between factors for free.
- Inside the SVM, the RBF kernel beats a linear one by +0.0139 AUC, so the terrain relationships genuinely are not straight lines.

Limitations to state alongside these numbers:
- The stable points are places with no recorded landslide, which is not the same as places where none can happen. Some of them are risky ground that has never been mapped, which caps how high any score here can go.
- Train and test rows were split at random, so points near each other in the landscape can land on both sides. Terrain is spatially correlated, so these scores are likely a little optimistic compared with predicting a region never seen.
